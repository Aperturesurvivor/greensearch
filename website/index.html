GreenSearch

Demo, not a live AI service

Chat like you would with ChatGPT or Gemini, but shorter by design. GreenSearch trims your question with PromptShrink, reuses an answer you already asked for when it can, and picks the shortest answer that still does the job.

Under each answer you see what that saved, compared with a regular verbose answer. The numbers are estimates, not measurements.

Why Finland matters, and what it does not change here

GreenSearch is meant to run where electricity is almost carbon-free. The reference point Grant chose is Google Cloud in Finland.

  • Google Cloud Finland (europe-north1): 98% carbon-free energy, grid intensity 30 gCO2eq/kWh.
  • Google Hamina site: 97% carbon-free energy.
  • Google data centers globally: 65% carbon-free energy in 2025, for contrast.
Important split: This demo runs in your browser, not in Finland, and it has no live model behind it. So the Finland numbers do not change the CO2 numbers under each answer. The savings you see here come only from fewer tokens. Clean-energy hosting is a second, separate lever for a live version, and it is not added on top here, to avoid double counting.

Sources: Google Cloud region carbon data and Google 2026 Environmental Report.

How the numbers are worked out

Tokens: words x 1.33, minimum 1. CO2e: tokens x 0.0018 g.

Baseline for each message: your original question plus the full (Forest) answer for the same topic, with no trimming, no routing, and no reuse.

GreenSearch for each message: your trimmed question plus the routed answer (Sprout, Canopy, or Forest), or just the trimmed question on a cache hit, when an answer was already given in this session.

PromptShrink trims filler and verbose phrases from your question. It protects text inside code fences. Routing: Sprout if the trimmed question is 12 words or fewer, Forest if it is 35 words or more, has a complexity marker like "in detail" or "compare", or has 2 or more question marks, otherwise Canopy.

Honest limits

No live model, no backend, and nothing leaves this page. Answers are pre-written templates for the 6 topics above. Token and CO2 figures are arithmetic from those estimates, not measured energy use and not a bill. A regular LLM baseline here means the verbose/full version of the same answer, not a measured ChatGPT or Gemini query.

Built from the existing GreenSearch harness and PromptShrink + GreenSearch integration demo, with the same formulas and the same 6 templates. Mode names: the chat uses Sprout / Canopy / Forest, matching the site demo. The Python harness calls Forest "Full" - that name difference is still open, not hidden.
